# Lumen changes

## 1.2.0
- Branded Windows notebook icon and Inno Setup installer.
- Explorer file, folder and folder-background context menus.
- Default Apps registration for text and code extensions (Windows controls final choice).
- PDF page rendering, raster image previews and read-only DOCX text/table previews.
- Python 3.12/3.14 selection for source builds and script execution.
- Private per-instance localhost service with session-protected API.
- Safer text saves, encoding checks and unsaved-change prompts.
- Settings, compact toolbar, rounded scrollbars, release notification.
- Existing Sublime-style plugin shim retained; explicit trusted installs only.
- Full Sublime API compatibility, legacy DOC, native shell preview handlers and automatic installer download are not included.
