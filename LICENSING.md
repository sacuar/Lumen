# Licensing clarification needed

Lumen's repository has historically contained **an empty `LICENSE` file** and two README documents with contradictory "MIT" and "Open GNU" claims. An empty file does not grant a licence.

The maintainer must select and publish a licence, or explicitly document any intended proprietary terms, before the project can be represented as open source. In the meantime:

- Viewing source on GitHub is not equivalent to permission for redistribution or commercial reuse.
- Do not treat the previous placeholder licence statements as a reliable permission grant.
- Contributors should ask the maintainer about licence and contribution terms before sending original code.
- Third-party code and dependencies retain their own licences.

This page is a transparency notice, not a new licence or legal advice.
